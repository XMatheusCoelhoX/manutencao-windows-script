1. dism /online /cleanup-image /startcomponentcleanup

Esse comando remove versões antigas e não utilizadas de arquivos e componentes do Windows Update, o que pode liberar espaço e preparar o sistema para operações de reparo. Ele garante que seu armazenamento de componentes esteja em boas condições antes de prosseguir com reparos mais profundos.

2. dism /online /cleanup-image /restorehealth

Esse comando verifica se há corrupção no repositório de componentes e a repara baixando novos arquivos do Windows Update ou de uma fonte especificada. É essencial corrigir quaisquer problemas no repositório de componentes que possam causar problemas para o SFC (Verificador de arquivos do sistema).

3. sfc /scannow

Este comando verifica a integridade dos arquivos do sistema e substitui todos os arquivos corrompidos pela versão correta, usando o armazenamento de componentes reparado pelo comando anterior. Executá-lo por último garante que ele tenha acesso a um repositório de componentes limpo.

Por que esta Ordem? A execução de startcomponentcleanup primeiro prepara o sistema para reparo. O RestoreHealth garante que as próprias ferramentas de reparo não sejam comprometidas. O SFC pode então operar de forma eficaz, contando com o armazenamento de componentes agora limpo.
